# Address Book Management System

## Description
A menu-driven Address Book Management System developed using C programming.

## Features
- Add contacts
- Search contacts
- Edit contacts
- Delete contacts
- Display all contacts
- Save contact details using file handling

## Technologies Used
- C Programming
- Structures
- Pointers
- Functions
- File Handling
